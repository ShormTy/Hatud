Install Hatud

Hatud works in your phone’s browser too. Installing it just puts an icon on your home screen so it opens like an app. It is free.

Android phone

Download the Hatud app (Android, 1.3 MB)
  1. Tap the green button above, on your phone. Download only from this page.
  2. If the phone says the file may be harmful, or that it cannot install apps from this source, tap Settings and allow your browser (for example Chrome) to install apps. Then go back and open the file again. The words differ from phone to phone.
  3. Open the downloaded Hatud.apk and tap Install, then Open.
  4. When Hatud asks to use your location, tap Allow. Students use it to fill in the pickup point and drivers use it for the map. Hatud does not save it.
  5. Log in or sign up. Students need the invite code from the Hatud owner. Drivers wait for the owner to approve them.

If the app shows a web address bar at the top, uninstall it and install it again. If that does not help, write to the owner.

iPhone

There is no iPhone app file. Open hatud.web.app in Safari, tap the Share button, then Add to Home Screen.

Updates

When the website is updated, the app updates by itself. You only need to install again if the owner tells you a new app file is out.
